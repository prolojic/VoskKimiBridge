# VoskKimiBridge

Офлайн-мост «речь → текст» для Windows: микрофон → **Whisper large-v3 (основной движок, GPU Vulkan)** → буфер обмена. Распознанный текст копируется в буфер, вставка — **Ctrl+V**. Работает полностью без интернета.

Как это работает:

- **Vosk** слушает в реальном времени и показывает промежуточный текст (индикация «Слушаю…»), но в буфер обмена его не отправляет.
- При выключении микрофона весь записанный звук сессии уходит в **Whisper** (large-v3, рантайм Vulkan — работает на любой современной видеокарте без CUDA). Результат правится по словарю терминов `terms.json` и копируется в буфер обмена.
- Если Whisper не загрузился или упал — автоматический фолбэк на финальный текст Vosk.
- Защита от галлюцинаций: Whisper не вызывается, если Vosk не услышал речи (тишина/шум), плюс чёрный список типичных галлюцинаций («Продолжение следует…» и т.п.).

## Возможности

- Плавающая кнопка «🎤 Микрофон» в правом нижнем углу экрана — всегда поверх окон (вкл./выкл. мышью).
- Горячие клавиши: **Insert** — вкл./выкл. микрофона, **Win+Insert** — выход.
- Значок в трее: двойной клик — вкл./выкл., правый клик — меню («Выход»).
- Текст всей сессии накапливается в буфере обмена и обновляется после каждой фразы.
- Всплывающие уведомления с распознанными фразами.
- Словарь технических терминов `terms.json` (Revit, Navisworks, AutoCAD, GitHub… 460+ форм): замена на точные английские написания после распознавания + тот же список передаётся Whisper как промпт. Файл подхватывается на лету, без перезапуска.
- Журнал работы: `%USERPROFILE%\vosk-kimi\bridge.log`.

## Требования

- Windows 10/11 (x64).
- .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
- Русская модель Vosk **vosk-model-ru-0.42** (~3,5 ГБ, не входит в репозиторий):
  скачать с https://alphacephei.com/vosk/models и распаковать архив.
- Модель Whisper **ggml-large-v3.bin** (~3,0 ГБ, не входит в репозиторий):
  скачать с https://huggingface.co/ggerganov/whisper.cpp/tree/main (файл `ggml-large-v3.bin`).

Пути к моделям ищутся в таком порядке (править код не нужно):

1. `C:\Users\vm1\vosk-kimi\models\…` (основной ПК автора);
2. `%USERPROFILE%\vosk-kimi\models\…` — **рекомендуемый вариант для нового компьютера**;
3. `models\…` рядом с exe.

## Установка на новый компьютер

1. Установить .NET 8 SDK.
2. `git clone https://github.com/prolojic/VoskKimiBridge.git`
3. Скачать обе модели (ссылки выше) и положить в `%USERPROFILE%\vosk-kimi\models\`:
   - `vosk-model-ru-0.42\` (папка из архива);
   - `ggml-large-v3.bin`.
4. Собрать:

   ```bat
   dotnet build -c Release
   ```

5. Запустить: `bin\Release\net8.0-windows\VoskKimiBridge.exe`.
   Загрузка модели Vosk занимает 1–3 минуты (~5,6 ГБ в памяти), Whisper догружает­ся в фоне за несколько секунд (в логе строка `Whisper готов …, рантайм: Vulkan`).

Нативные рантаймы Whisper (Vulkan + CPU-фолбэк) лежат в репозитории в `whisper-runtimes\`
и при сборке копируются в `runtimes\…` рядом с exe — отдельно ничего ставить не нужно.

## Автозапуск

Скрипт `vosk_kimi_bridge.vbs` запускает мост без окна консоли. Скопируйте его в папку
автозагрузки — `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` — и проверьте,
что путь к `VoskKimiBridge.exe` внутри скрипта соответствует вашему расположению.

## Как пользоваться

1. Нажмите **Insert** (или кнопку «🎤 Микрофон») — услышите сигнал, микрофон включён.
2. Говорите — можно несколькими фразами. Промежуточный текст показывается в уведомлениях.
3. Нажмите **Insert** ещё раз — появится «Распознаю (Whisper)…», через несколько секунд
   готовый текст окажется в буфере обмена.
4. Вставьте текст в любое поле: **Ctrl+V**.

Whisper думает примерно 0,5–1 с на секунду речи (зависит от видеокарты). На длинной
диктовке ожидание почти незаметно.

## Структура

- `Program.cs` — вся логика: low-level хук клавиатуры (WH_KEYBOARD_LL), NAudio-захват
  микрофона, распознавание (Whisper + Vosk), защита от галлюцинаций, буфер обмена,
  трей, плавающая кнопка.
- `VoskKimiBridge.csproj` — .NET 8 (net8.0-windows, WinForms), пакеты Vosk 0.3.38,
  NAudio 2.2.1, Whisper.net 1.9.1 (+ рантаймы Vulkan и CPU).
- `terms.json` — словарь терминов для пост-обработки и промпта Whisper (hot-reload).
- `whisper-runtimes\` — нативные DLL Whisper (Vulkan для GPU, CPU-фолбэк).
- `vosk_kimi_bridge.vbs` — скрипт автозапуска (см. раздел «Автозапуск»).
- `vosk_watchdog.ps1` — сторож: поднимает мост, если он упал.

## Примечания

- Горячие клавиши зависят от того, доходит ли клавиатурный ввод до системы
  (в некоторых VM/сценариях доставки ввода хуки ничего не видят) — кнопка и трей работают всегда.
- Модели большие и распространяются отдельно (Vosk — Apache 2.0; Whisper — MIT).
- Без видеокарты Whisper автоматически перейдёт на CPU-рантайм — медленнее, но работает.
