# VoskKimiBridge

Офлайн-мост «речь → текст» для Windows: микрофон → распознавание Vosk (русская модель) → буфер обмена. Распознанный текст копируется в буфер, вставка — **Ctrl+V**. Работает полностью без интернета.

## Возможности

- Плавающая кнопка «🎤 Микрофон» в правом нижнем углу экрана — всегда поверх окон (вкл./выкл. мышью).
- Горячие клавиши: **Insert** — вкл./выкл. микрофона, **Win+Insert** — выход.
- Значок в трее: двойной клик — вкл./выкл., правый клик — меню («Выход»).
- Текст всей сессии накапливается в буфере обмена и обновляется после каждой фразы.
- Всплывающие уведомления с распознанными фразами.
- Журнал работы: `%USERPROFILE%\vosk-kimi\bridge.log`.

## Требования

- Windows 10/11 (x64).
- .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
- Русская модель Vosk **vosk-model-ru-0.42** (~3,5 ГБ, не входит в репозиторий):
  скачать с https://alphacephei.com/vosk/models и распаковать архив.

## Установка

1. Скопируйте папку проекта на компьютер.
2. Распакуйте модель, например в `C:\Users\<user>\vosk-kimi\models\vosk-model-ru-0.42`.
3. При необходимости поправьте путь к модели в начале `Program.cs`:

   ```csharp
   private const string ModelPath = @"C:\Users\<user>\vosk-kimi\models\vosk-model-ru-0.42";
   ```

4. Соберите:

   ```bat
   dotnet build -c Release
   ```

5. Запустите: `bin\Release\net8.0-windows\VoskKimiBridge.exe`.
   Загрузка модели занимает 1–3 минуты, в памяти ~5,6 ГБ.

## Автозапуск

Скрипт `vosk_kimi_bridge.vbs` запускает мост без окна консоли. Скопируйте его в папку
автозагрузки — `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup` — и проверьте,
что путь к `VoskKimiBridge.exe` внутри скрипта соответствует вашему расположению.

## Как пользоваться

1. Нажмите кнопку «🎤 Микрофон: ВЫКЛ — вкл.» (станет розовой «ВКЛ»).
2. Говорите — можно несколькими фразами. Каждая фраза добавляется в буфер обмена.
3. Нажмите кнопку ещё раз.
4. Вставьте текст в любое поле: **Ctrl+V**.

Буфер можно вставлять и в середине сессии — он всегда содержит всё распознанное
с момента включения микрофона. При новом включении буфер сессии очищается.

## Структура

- `Program.cs` — вся логика: low-level хук клавиатуры (WH_KEYBOARD_LL), NAudio-захват
  микрофона, распознавание Vosk, буфер обмена, трей, плавающая кнопка.
- `VoskKimiBridge.csproj` — .NET 8 (net8.0-windows, WinForms), пакеты Vosk 0.3.38 и NAudio 2.2.1.
- `vosk_kimi_bridge.vbs` — скрипт автозапуска (см. раздел «Автозапуск»).

## Примечания

- Горячие клавиши зависят от того, доходит ли клавиатурный ввод до системы
  (в некоторых VM/сценариях доставки ввода хуки ничего не видят) — кнопка и трей работают всегда.
- Модель `vosk-model-ru-0.42` большая и распространяется отдельно (лицензия Apache 2.0, Vosk).
